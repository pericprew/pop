Pop! Buddy 隱私權政策網站替換說明

1. 前往 https://github.com/pericprew/pop
2. 若網站原本使用根目錄 index.html，點選該檔並使用 Edit（鉛筆圖示），將內容換成新版 index.html 的全部內容。
   或使用 Add file → Upload files 上傳本檔，取代同名的 index.html。
3. Commit changes。
4. 等待 GitHub Pages 部署後，開啟 https://pericprew.github.io/pop/ 確認頁面更新。
5. 若原網站的入口不是根目錄 index.html，請確認 GitHub Pages 的發布來源後替換對應檔案，勿覆蓋其他功能頁面。

注意：此頁僅依已知整合 AdMob 的情況起草。送審前應核對真實 SDK 版本、ATT 同意流程、Firebase/其他 SDK、兒童導向設定、是否有帳號與其他資料收集。網頁內容不會自動修改 Apple App Store Connect 的資料類型，也不能取代程式端的權限設定。
